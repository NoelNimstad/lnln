# lnln.zig

lnln är ett databehandlingsprogram som läser in en `.csv` fil i samband med en
osäkerhet i båda dimensioner, och ger en fin $\LaTeX$-formaterad graf (genom
tikz och pgfplots), samt dess lutning, lutningens osäkerhet och ett $R^2$ värde.

## Hur använder jag lnln?

För en CLI-version av lnln, clone:a `master`, för en GUI (genom raygui), se
`gui` branch:en.
